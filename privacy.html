Privacy Policy

Last updated: 14 October 2026 · Website preview

This page covers the current preview website. Product release terms and operator contact details are pending.

Scope

This policy describes the current informational website and browser demo. It does not describe a released desktop application. A separate, complete application privacy policy will be provided before software distribution.

Information you enter

There are no accounts, email sign-ups, payment forms, or contact forms implemented in this website. Library searches and download-control interactions are processed in your browser. This website code does not send those values to a server or store them persistently.

Language and region

The website reads your browser language preference locally to show a regional label in the footer. The page content is in English. It does not request your precise location, use GPS, or transmit the detected region through application code.

Cookies and analytics

The website code does not set cookies, use local storage, or include an analytics or advertising tracker. Hosting and private-site access services may use their own cookies and process request metadata according to their policies.

Fonts and hosting

Font files are requested from Google Fonts. Those requests expose ordinary connection information, such as your IP address, to the font provider. Your browser uses system font fallbacks if the font service is unavailable. The hosting provider receives information required to deliver this website, including request and network metadata. Its retention practices are governed by its own policies.

Your choices

You can limit external font requests through your browser settings or extensions. No personal information submitted through this website is retained by its application code. Operator contact details and information-request procedures will be published before the production app launch.

Changes

This policy may change as the website and product develop. Any accounts, telemetry, cloud features, or additional data processing introduced in a future release will require updated disclosures.
